# 🎮 俄羅斯方塊遊戲 (Tetris)

一個功能豐富、界面精美的經典俄羅斯方塊遊戲，使用純 HTML、CSS 和 JavaScript 開發。

## ✨ 遊戲特色

### 核心功能
- 🎯 **經典玩法**：7種經典俄羅斯方塊（I、O、T、S、Z、J、L）
- 🔄 **旋轉系統**：採用 SRS (Super Rotation System) 標準旋轉系統
- 👻 **幽靈方塊**：顯示方塊落地位置預覽
- 💾 **保存功能**：可以保存當前方塊供後續使用
- ⚡ **瞬間下落**：空格鍵快速下落
- 📊 **完整統計**：分數、等級、消除行數即時顯示

### 遊戲系統
- 📈 **等級系統**：每消除10行升級，速度遞增
- 🏆 **計分系統**：
  - 單行消除：100分
  - 雙行消除：300分
  - 三行消除：500分
  - 四行消除（Tetris）：800分
  - 分數隨等級倍增
- 💯 **最高分記錄**：自動保存到本地存儲

### 界面特色
- 🎨 **現代化設計**：漸變色彩、毛玻璃效果
- ✨ **流暢動畫**：消行動畫、按鈕動效
- 📱 **響應式佈局**：支持桌面和移動設備
- 🎮 **觸控控制**：移動端專用觸控按鈕
- 🔊 **音效系統**：可選的遊戲音效

## 🎮 操作說明

### 鍵盤操作（桌面端）
| 按鍵 | 功能 |
|------|------|
| ← → | 左右移動方塊 |
| ↓ | 加速下落 |
| ↑ | 旋轉方塊 |
| Space | 瞬間下落到底部 |
| C | 保存/交換方塊 |
| P | 暫停/繼續遊戲 |

### 觸控控制（移動端）
- 屏幕下方提供專用觸控按鈕
- 包含左右移動、下落、旋轉、瞬降和保存功能

## 🚀 快速開始

### 方法1：直接打開
1. 下載所有文件到同一目錄
2. 雙擊 `index.html` 在瀏覽器中打開
3. 點擊"開始遊戲"或按空格鍵開始

### 方法2：本地服務器
```bash
# 使用 Python 3
python -m http.server 8000

# 使用 Python 2
python -m SimpleHTTPServer 8000

# 使用 Node.js (需要先安裝 http-server)
npx http-server
```

然後在瀏覽器訪問 `http://localhost:8000`

## 🎯 遊戲規則

1. **目標**：通過移動和旋轉下落的方塊，填滿橫向的行
2. **消行**：當一行完全填滿時，該行會被消除並獲得分數
3. **升級**：每消除10行提升一個等級，下落速度加快
4. **遊戲結束**：當方塊堆積到頂部無法生成新方塊時遊戲結束

## 💡 遊戲技巧

- 🎯 **利用幽靈方塊**：半透明的幽靈方塊顯示當前方塊會落在哪裡
- 💾 **保存功能**：遇到不想要的方塊可以保存起來，需要時再交換
- ⚡ **瞬間下落**：確定位置後使用空格鍵快速下落
- 🏆 **追求Tetris**：同時消除4行可獲得最高分數
- 📊 **關注進度條**：瞭解距離升級還需消除多少行

## 🎨 特色功能詳解

### 1. SRS 旋轉系統
- 標準的超級旋轉系統，支持 Wall Kick
- 在靠近牆壁或其他方塊時也能順利旋轉

### 2. 保存方塊
- 按 C 鍵可以保存當前方塊
- 每次放置方塊後可以保存一次
- 已保存的方塊會顯示在右側面板

### 3. 進度系統
- 即時顯示升級進度
- 進度條可視化展示
- 目標行數動態更新

### 4. 音效系統
- 移動、旋轉、下落等操作都有音效
- 可以通過按鈕開關音效
- 使用 Web Audio API 實現
